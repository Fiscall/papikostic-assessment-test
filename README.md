# Papikostik Assessment Test

This repository contains a free, public, online personality assessment inspired by a Papikostik-style questionnaire.

## Features
- Public web page
- Instant personality result
- No login required
- No backend required
- Fully static and free to host on GitHub Pages

## Files
- `index.html` — main assessment page
- `style.css` — styling
- `script.js` — scoring logic

## Run locally
Open `index.html` in your browser, or serve the folder with a simple local web server.

Example:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Publish publicly with GitHub Pages
1. Push this repository to GitHub.
2. Go to the repository settings.
3. Open the "Pages" section.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Select the `main` branch and save.
6. Your site will be published at:

```text
https://<your-username>.github.io/papikostic-assessment-test/
```

## Notes
This is a simple assessment model for demonstration and open use. You can customize the questions, scoring, and final interpretations to match your preferred personality model.
